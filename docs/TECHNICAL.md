# 技术说明

## 平台与模块

App 0.2.0；Tactility SDK 0.7.0；ESP-IDF 5.5.2；ESP32-S3。外部 ELF App，manifest schema 0.1，SDK/平台和字段大小写均固定。

| 文件 | 职责 |
|---|---|
| main/main.c | LVGL 页面、输入/菜单、任务生命周期、音频与 SD 操作 |
| main/dict_core.c | 定长索引查找、数据解析、候选、文件名和 WAV 验证 |
| main/shift_paging.h | 5×7 键盘矩阵中的左右 Shift 边沿识别 |
| main/sd_font.c | SD 上 18px 字形加载、缓存与绘制 |
| main/online.c | HTTPS、取消/超时、有界重试、响应验证、诊断 |
| main/unipus.c | 官方试用鉴权及英汉释义/双语例句格式化 |

## 数据与输入

复用 cardputer-dict-local-v1 格式，不将全词库装入 RAM。英汉和汉英定长索引二分查找，再从 dat 随机读取对应条目；拼音索引按前缀查询，逐组输出五个候选。数据快照及 SHA-256 见 data-manifest.json。字库含 30,890 个字形，按需从 SD 读取；覆盖面不是完整 Unicode。

左右 Shift 通过现有键盘矩阵能力读取并作边沿检测，不把普通 u/d 输入用于候选翻页。麦克风键保留独立 0xF0 事件处理，但当前宿主透传未验收；ASCII 0 不触发发音。

## 音频修复

本地 WAV 为 48kHz 16-bit PCM。单声道流复制成左右两路后送系统双声道 I2S，避免声道解释与速度不匹配。词头到音频文件名转换采用明确 ASCII 判断，不依赖宿主导出的 _ctype_ 表布局。此前 apple/ball 的文件名误映射属于运行时转换问题，不是 WAV 内容本身损坏。

## 任务、内存与联网

本地工作线程和网络 pthread 分离，16KiB 栈；GUI 不同步等待 TLS。Tactility Thread 与 IDF pthread 的 FreeRTOS TLS slot 0 存在语义冲突，创建网络 pthread 时临时清空调用者 slot，创建后恢复；退出时取消并 join，避免卸载后继续执行。

网络响应上限 32KiB，使用 PSRAM；限制完整 JSON、预期结构及声明长度，禁止把两次尝试的部分响应拼接。两次新客户端尝试共用预算；第一次默认 TLS，必要时第二次使用 TLS 1.2 兼容路径，始终验证证书。系统默认超时与 UI 最终超时分离，旧请求不覆盖新查询。

外研路径：POST /openapi/dict/v1/keyword/1/1，body 为 JSON name；O/E 使用同一返回结构选择释义或例句展示。鉴权按官方文档，以 Unix 秒数字符串做 AES-256-CBC、PKCS7、Base64，IV 固定为官方规定的 1..16。该算法仅用于兼容提供者协议，不是本项目设计的通用认证方案。

源码中的试用 appId/secret 由提供者公开发布。不要把自己的生产凭据提交进公共仓库，也不要把公开试用当作永久授权。当前 CA 为公开 Sectigo E46 根，证书轮换后可能需要重新构建 roots.pem。

## 系统触屏修正

原生 esp_lvgl_port 在 GT911 配置了中断脚时使用 LVGL EVENT 输入模式。针对本机“进入页面后最初几秒可用，随后无响应”的现象，板级补丁将 pinInterrupt 从 GPIO16 改为 GPIO_NUM_NC，让 LVGL 原生 TIMER 以既有 17ms 周期持续读取。仍由系统驱动读坐标、确认 GT911 状态，不在 App 中伪造触点，也不写 GT911 配置 EEPROM。

一台设备已确认系统及词典触屏恢复。该结果说明此读取方式在测试设备有效，不证明所有失效均由同一种 IRQ 根因造成。持续轮询有待机功耗取舍，长期运行及其他硬件仍需验证。

## 验证记录与边界

- 30,000 个源 WAV 完成文件名映射、头与长度验证；SD 名称/大小匹配，无缺失。不是逐个试听。
- Shift 全矩阵位置、按下/保持/松开、组合键及无效帧检查。
- 6 项 Enter 路由检查；17 项重试故障注入；8 项接收边界；14 项 JSON 完整性；11 项 TCP 诊断检查；官方鉴权向量及合成响应格式化。
- 原设备构建所需 180 个系统导入符号通过核对；编译限制单栈帧不超过 8192 字节。
- 用户实测：离线输入/释义、apple/hello 发音、Shift 翻组、轨迹球/正文翻页、在线查询与修正版触屏通过。
- 公开构建仅将原本写死的本地 SSID 报错文字换成通用网络提示，并更新资源 NOTICE；未改变检索和联网算法。公开包的设备安装流程未另做一次实机验收，包格式及宿主解析兼容性单独验证。
