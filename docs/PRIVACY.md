# 公开内容与脱敏

公开源代码和 `.app` 已移除开发机 Wi-Fi 名称提示。未包含设备 Flash 备份、NVS、Wi-Fi 密码、私有 API 凭据、MAC、设备 IP、查询历史、收藏、原始串口日志或 Windows 用户目录。安装包的 USTAR 所有者名称清空，UID/GID 归零；包内文件也按隐私标记扫描。

保留正常的版权署名、公开 GitHub 项目归属及上游许可证。提交使用 GitHub noreply 邮箱。外研试用 appId/secret 由提供者公开文档发布，源码明确标注为公开接入试用，并非开发者私有凭据；长期使用应另行确认授权。公开信任根证书不含私钥。

App 在用户设备运行时会生成查询历史、收藏和诊断日志；这些运行时文件不随本项目分发，分享设备日志前应自行审阅。
